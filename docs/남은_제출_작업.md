# 제출 확인

공통평가 02 제출 저장소는 https://github.com/sylee21c/PhotoBlogProject02 입니다. 공통평가 01 저장소와 구분합니다.

보고서에는 폴더 구조, 소스, 로컬 API와 사진 조회, Android 화면, PythonAnywhere API와 사진 조회, Edge 자동 전송 및 두 편의 기능의 증빙을 해당 항목 바로 아래에 넣었습니다.

클라우드 서비스는 https://blackponge.pythonanywhere.com/ 입니다. 게시글 1번은 선택한 로컬 사진을 브라우저로 등록한 결과입니다. 게시글 2~6번은 실제 웹캠 검출기를 실행해 자동 전송한 결과이며 sent=5, pending=0, blocked=0을 확인했습니다. API와 사진 응답은 모두 HTTP 200이었습니다.

학번과 이름은 요청에 따라 비워 두었습니다. 보고서에 직접 작성하고 수정한 파일을 저장소에 다시 반영한 뒤 과제 제출란에 GitHub URL을 제출합니다. 평가자 판정 칸은 작성하지 않습니다.

이 제출 폴더에는 이전 임시 촬영 자료와 로컬 인증정보를 제외했습니다. 기존 작업 폴더의 과거 Git 이력 대신 새 제출 이력을 사용합니다.
